# Rocket 3D 4All

브라우저에서 실행되는 인터랙티브 로켓 비행 시뮬레이터입니다.  
사용자가 로켓의 질량, 연료량, 추력, 비추력, 발사각, 항력, 바람 조건을 조정하면 RK4 기반 물리 엔진이 비행 궤적을 계산하고, 결과를 2D 차트와 3D 뷰포트, 미션 분석 리포트로 시각화합니다.

이 프로젝트는 단순한 그래프 데모가 아니라 `입력 -> 물리 시뮬레이션 -> 텔레메트리 생성 -> 시각화 -> 분석 리포트`로 이어지는 하나의 작은 비행 분석 도구를 목표로 합니다.

## 프로젝트 개요

`Rocket 3D 4All`은 교육용/포트폴리오용 로켓 비행 시뮬레이션 웹 애플리케이션입니다.

사용자는 슬라이더로 로켓 파라미터를 바꾸고, 즉시 바뀌는 비행 결과를 확인할 수 있습니다. 시뮬레이션 결과는 단순한 최종 수치만 보여주지 않고, 시간별 텔레메트리, 궤적, 이벤트, 현재 위치, 3D 재생, 위험도 분석까지 연결됩니다.

### 설계 목표

- 물리 계산과 UI를 분리해 유지보수 가능한 구조 만들기
- 수치 결과를 차트와 3D 장면으로 동시에 표현하기
- 사용자가 파라미터를 조정하며 결과 변화를 탐색할 수 있게 하기
- 포트폴리오에서 설명 가능한 엔지니어링 지표 제공하기
- GitHub Pages에 배포 가능한 정적 웹앱으로 구성하기

## 핵심 기능

### 비행 시뮬레이션

- RK4 수치 적분 기반 궤적 계산
- 상태 벡터 `[x, y, vx, vy, mass]` 기반 시뮬레이션
- 연료 소모에 따른 질량 변화 반영
- 추력, 중력, 항력, 바람, 대기 밀도 반영
- 발사 레일 구간 처리
- 추력이 초기 중량보다 낮으면 이륙 불가 상태 처리

### 시각화

- 2D 비행 궤적 차트
- 고도, 속도, 가속도, 동압 텔레메트리 차트
- 현재 재생 위치를 궤적 차트와 텔레메트리 차트에 표시
- 3D 뷰포트에서 로켓 비행 재생
- 3D 재생 시간과 2D 차트 커서 동기화
- 이벤트 타임라인 제공

### 분석 및 리포트

- 미션 점수 자동 산출
- 추력대중량비, 연료 비율, Max-Q 위험도, 착지 충격 분석
- 이론 Delta-V, 탄도계수, 레일 이탈 속도, 연소 후 상승 비율 계산
- ISA 대기 상태 기반 Mach/Reynolds 수 계산
- 천음속/초음속 이벤트 추출
- 설정별 개선 제안 자동 생성
- Markdown 리포트 복사
- 텔레메트리 CSV 내보내기
- 현재 설정과 프리셋을 비교하는 시나리오 랩
- 목표별 자동 튜닝 후보 제안
- 일반 모델과 전문 모델 전환
- 프리셋 JSON 저장 및 불러오기
- 전문 모델 전용 비행 검증 게이트
- 전문 모델 전용 불확실성 스윕

## 시뮬레이션 모델

### 상태 벡터

```text
[x, y, vx, vy, mass]
```

각 항목의 의미는 다음과 같습니다.

| 항목 | 의미 | 단위 |
| --- | --- | --- |
| `x` | 수평 위치 | m |
| `y` | 고도 | m |
| `vx` | 수평 속도 | m/s |
| `vy` | 수직 속도 | m/s |
| `mass` | 현재 질량 | kg |

### 기본 운동 방정식

```text
dx/dt  = vx
dy/dt  = vy
dvx/dt = (thrust_x - drag_x) / mass
dvy/dt = (thrust_y - drag_y) / mass - gravity
dm/dt  = -massFlowRate
```

### 반영된 물리 요소

| 요소 | 구현 내용 |
| --- | --- |
| 추력 | 발사각 기준으로 x/y 성분 분해 |
| 연료 소모 | `thrust / (Isp * g0)` 기반 질량 감소 |
| 중력 | 고도에 따른 중력 변화 반영 |
| 항력 | 동압, 항력계수, 기준면적 기반 계산 |
| 대기 밀도 | ISA 표준대기 기반 고도별 밀도 모델 |
| 바람 | 공기 상대속도 기준 항력 계산 |
| 발사 레일 | 레일 이탈 전에는 레일 방향 가속으로 제한 |
| Mach 수 | 고도별 온도와 음속 기반 계산 |
| Reynolds 수 | 공기 밀도, 상대속도, 특성 길이, 점성계수 기반 계산 |
| Mach 기반 Cd 보정 | 천음속/초음속 구간에서 항력계수 보정 |
| 공력가열 지표 | Sutton-Graves 형태의 간이 열유속 지표 계산 |
| 손실 추정 | 항력 손실과 중력 손실을 텔레메트리 기반으로 추정 |

### 대기 및 공력 지표

대기 모델은 고도별 온도, 압력, 밀도, 음속, 동점성 추정값을 계산합니다. 이를 통해 단순한 포물선 운동이 아니라 공력 환경의 변화를 함께 분석할 수 있습니다.

| 지표 | 계산 의미 |
| --- | --- |
| `Mach` | 공기 상대속도 / 현 고도 음속 |
| `Reynolds number` | 관성력과 점성력의 상대적 크기 |
| `Dynamic pressure` | 구조 하중과 Max-Q 판단에 사용 |
| `Transonic event` | Mach 0.8 이상에 처음 진입한 시점 |
| `Supersonic event` | Mach 1.0 이상에 처음 진입한 시점 |
| `Heat flux` | 노즈 반경과 밀도, 속도를 이용한 공력가열 proxy |
| `Drag / gravity loss` | 이상 Delta-V 대비 손실 해석에 활용하는 보조 지표 |

## 미션 분석 패널

미션 분석 패널은 시뮬레이션 결과를 포트폴리오에서 설명하기 쉬운 형태로 요약합니다.

### 자동 평가 항목

| 지표 | 설명 |
| --- | --- |
| 미션 점수 | 이륙 가능성, 추력대중량비, Max-Q, 착지 속도 등을 종합한 점수 |
| 추력대중량비 | 초기 추력이 로켓 중량을 얼마나 이길 수 있는지 평가 |
| 연료 비율 | 전체 질량 대비 연료 비율 |
| Max-Q 위험도 | 최대 동압 기반 구조 하중 위험도 |
| 착지 충격 | 착지 속도 기반 회수 위험도 |
| 이론 Delta-V | Tsiolkovsky 방정식 기반 이상적인 속도 변화량 |
| 탄도계수 | 질량, 항력계수, 기준면적 기반 공력 특성 지표 |
| 레일 이탈 속도 | 발사 레일을 벗어나는 순간의 속도 |
| 연소 후 상승 | 연소 종료 이후 관성으로 추가 상승한 비율 |
| 최대 Mach | 비행 중 도달한 최대 마하수 |
| 최대 Reynolds 수 | 비행 중 공력 레짐의 최대 Reynolds 수 |

### 내보내기 기능

- `Markdown 리포트 복사`: 현재 입력값, 주요 결과, 공학 지표를 Markdown 형식으로 복사합니다.
- `텔레메트리 CSV 저장`: 시간별 위치, 속도, 가속도, 질량, 추력, 항력, 동압, Mach, Reynolds 데이터를 CSV로 저장합니다.

## 모델 설정

왼쪽 패널의 `모델 설정`에서 시뮬레이션 복잡도를 전환할 수 있습니다.

| 모델 | 계산 방식 | 용도 |
| --- | --- | --- |
| 일반 모델 | 상수 중력, 해수면 대기, 일정 추력 | 빠른 비교, 교육용 실험, 단순 궤적 확인 |
| 전문 모델 | 고도별 대기, 중력 변화, 추력 램프, Mach/Reynolds | 포트폴리오용 분석, 공력 지표 확인, 이벤트 추출 |

모델을 전환하면 현재 파라미터는 유지한 상태로 시뮬레이션 결과만 즉시 재계산됩니다. 프리셋 비교와 튜닝 어시스턴트도 선택된 모델 기준으로 동작합니다.

## 비행 검증 게이트

전문 모델에서는 `Flight Readiness Review` 패널이 표시됩니다. 이 패널은 단순 수치 나열이 아니라 설계 검토에 가까운 형태로 위험 항목을 분류합니다.

| 게이트 | 기준 |
| --- | --- |
| 레일 이탈 안정성 | 레일을 벗어나는 순간의 속도 |
| 구조 하중 Max-Q | 최대 동압 기반 하중 위험도 |
| 압축성 영역 | 최대 Mach 기준 천음속/초음속 진입 여부 |
| 공력가열 | 간이 열유속 proxy |
| 손실 비율 | 항력 손실과 중력 손실의 상대 규모 |
| 착지 속도 | 회수/착지 위험도 |

각 항목은 `Pass`, `Watch`, `Risk`로 분류됩니다. 실제 발사 인증을 대체하는 값은 아니지만, 포트폴리오에서는 “시뮬레이션 결과를 기준으로 의사결정 가능한 품질 게이트를 만들었다”는 점을 보여줄 수 있습니다.

## 불확실성 분석

전문 모델에서는 `Uncertainty Sweep` 패널을 사용할 수 있습니다. 현재 설정 주변의 추력, 질량, 항력계수, 바람, 발사각 오차를 샘플링해 결과 분포를 계산합니다.

| 출력 | 의미 |
| --- | --- |
| P10 | 하위 10% 수준의 보수적 결과 |
| P50 | 중앙값 결과 |
| P90 | 상위 90% 수준의 낙관적 결과 |
| 실패 샘플 | 오차 조건에서 이륙 조건을 만족하지 못한 케이스 수 |

분석 대상은 최대 고도, 사거리, Max-Q, 최대 Mach, 공력가열, 착지 속도입니다. 이 기능은 단일 결과값보다 실제 설계 검토에 가까운 “결과 범위”를 보여줍니다.

## 시나리오 비교 패널

시나리오 비교 패널은 현재 설정과 내장 프리셋을 같은 물리 엔진으로 재계산해 성능을 비교합니다.

### 비교 기준

| 항목 | 설명 |
| --- | --- |
| 최고 고도 | 각 시나리오의 최대 고도 비교 |
| 최장 사거리 | 수평 도달 거리 비교 |
| 균형 점수 | 이륙 가능성, 추력대중량비, Max-Q, 착지 속도를 반영한 점수 |
| Max-Q | 구조 하중 위험도를 보기 위한 최대 동압 |
| 추력대중량비 | 발사 초반 가속 여유 비교 |

### 활용 방식

1. 현재 파라미터를 조정합니다.
2. 시나리오 비교 패널에서 프리셋과 현재 설정의 성능을 비교합니다.
3. 고도, 사거리, 안정성 중 목표에 맞는 프리셋을 선택합니다.
4. `적용` 버튼으로 프리셋을 불러온 뒤 세부 파라미터를 다시 튜닝합니다.

이 기능은 단일 시뮬레이션 결과만 보여주는 것이 아니라 여러 설계안을 비교하는 흐름을 제공하기 때문에, 포트폴리오에서 “실험과 의사결정을 지원하는 UI”로 설명할 수 있습니다.

## 튜닝 어시스턴트

튜닝 어시스턴트는 현재 파라미터 주변을 자동 탐색해 목표별 추천 설정을 제안합니다.

### 탐색 대상

| 파라미터 | 탐색 방식 |
| --- | --- |
| 발사각 | 현재 값 주변의 낮은 각도와 높은 각도 비교 |
| 추력 | 현재 추력의 감속/유지/증가 후보 비교 |
| 추력 램프 | 완만한 추력 상승과 빠른 추력 상승 비교 |
| 항력계수 | 현재 형상보다 낮거나 높은 항력 후보 비교 |

### 추천 목표

| 목표 | 기준 |
| --- | --- |
| 고도 우선 | 최대 고도를 가장 크게 만드는 후보 |
| 사거리 우선 | 수평 도달 거리를 가장 크게 만드는 후보 |
| 안정성 우선 | 추력대중량비, Max-Q, 착지 속도를 종합한 후보 |

각 추천 카드는 예상 고도, 사거리, 발사각, 추력, 추력 램프, Cd 값을 보여주며 `이 후보 적용` 버튼으로 바로 현재 파라미터에 반영할 수 있습니다.

이 기능은 사용자가 직접 수십 번 슬라이더를 조정하지 않아도 목표에 가까운 설계 방향을 빠르게 찾을 수 있게 해줍니다.

## 프리셋 JSON 입출력

왼쪽 프리셋 패널에서 현재 설정을 JSON으로 저장하거나, 이전에 저장한 JSON 파일을 다시 불러올 수 있습니다.

저장되는 항목은 다음과 같습니다.

| 항목 | 설명 |
| --- | --- |
| `schema` | 프리셋 파일 식별자 |
| `version` | JSON 스키마 버전 |
| `modelMode` | 일반 모델 또는 전문 모델 |
| `params` | 질량, 연료, 추력, Isp, 발사각, Cd, 단면적, 바람 등 입력 파라미터 |

이 기능을 이용하면 특정 실험 조건을 파일로 보관하거나, 포트폴리오 시연 시 같은 조건을 빠르게 복원할 수 있습니다.

## 사용자 흐름

1. 프리셋을 선택하거나 직접 파라미터를 조정합니다.
2. 일반 모델 또는 전문 모델을 선택합니다.
3. 시뮬레이션 실행 버튼으로 현재 설정을 고정합니다.
4. 3D 뷰포트에서 비행을 재생합니다.
5. 2D 궤적 차트에서 현재 위치를 확인하거나 직접 드래그합니다.
6. 텔레메트리 차트에서 시간별 고도, 속도, 가속도, 동압 변화를 확인합니다.
7. 미션 분석 패널에서 주요 공학 지표를 확인합니다.
8. 시나리오 비교 패널에서 다른 프리셋과 성능을 비교합니다.
9. 튜닝 어시스턴트에서 목표별 추천 후보를 적용합니다.
10. 필요한 경우 Markdown 리포트나 CSV 데이터를 내보냅니다.

## 포트폴리오 관점

이 프로젝트에서 강조할 수 있는 지점은 다음과 같습니다.

### 1. 물리 엔진과 UI의 분리

시뮬레이션 로직은 `src/physics`에 분리되어 있고, React 컴포넌트는 계산된 텔레메트리를 시각화하는 역할을 맡습니다. 이 구조는 기능 확장이나 테스트 작성이 쉬운 편입니다.

### 2. 인터랙티브 데이터 시각화

같은 텔레메트리 데이터를 2D 차트, 3D 장면, 이벤트 타임라인, 분석 패널에서 동시에 사용합니다. 사용자가 차트에서 시간을 조정하면 3D 화면도 같은 시점으로 이동합니다.

### 3. 엔지니어링 지표 자동 해석

단순히 “높이 올라갔다”를 보여주는 것이 아니라 추력대중량비, Delta-V, Max-Q, 탄도계수, 착지 위험도처럼 설명 가능한 공학 지표를 제공합니다.

### 4. 시나리오 기반 의사결정 UI

여러 프리셋을 같은 기준으로 비교해 고도형, 사거리형, 안정형 설계를 구분할 수 있습니다. 단일 결과 화면보다 실제 분석 도구에 가까운 사용자 경험을 제공합니다.

### 5. 자동 튜닝 후보 생성

현재 설정 주변의 파라미터 조합을 재계산해 목표별 후보를 제시합니다. 이는 단순 입력 UI를 넘어 “실험 자동화”에 가까운 기능입니다.

### 6. 배포 가능한 프론트엔드 제품 형태

Vite 기반 정적 웹앱으로 구성되어 GitHub Pages에 배포할 수 있습니다. 로컬 실행용 `run.bat`, 자동 배포 워크플로우, 반응형 UI를 포함합니다.

## 개선 방향

현재 구현은 교육용/포트폴리오용 2D+3D 비행 시뮬레이션입니다. 더 전문적인 시뮬레이터로 확장하려면 다음 방향이 적합합니다.

| 개선 항목 | 설명 |
| --- | --- |
| Mach 기반 항력 모델 | 속도 영역별 Cd 변화를 반영 |
| 추력 곡선 입력 | 일정 추력이 아니라 시간별 엔진 추력 프로파일 반영 |
| 다단 로켓 | 스테이지 분리, 질량 변화, 재점화 이벤트 구현 |
| Monte Carlo 분석 | 바람, 질량, 추력 오차를 랜덤 샘플링해 민감도 분석 |
| 회수 시스템 | 낙하산 전개, 착지 감속, 회수 성공률 계산 |
| 테스트 보강 | 물리 계산 단위 테스트와 주요 시나리오 회귀 테스트 추가 |
| 모바일 최적화 | 3D 렌더링 품질 단계와 저사양 모드 추가 |
